# Hardware precharge-controller
Hardware-only precharge controller design for the E-Agle Trento Racing Team electronics recruitment test.
[Project task](https://github.com/eagletrt/recruitment-hw/tree/master/task-3)


## Project structure
- `./docs`:
  - `datasheet`: Datasheets of all the used components
  - `img`: Images used in markdown files
  - `DESCRIPTION.md`: Description file containing a complete overview about the project   
- `./hardware`:
  - `libs`: Libraries used in kicad project
  - `sim`: LTspice simulation files
  - `kicad files`
